# EloGG

## Status do Projeto
> Em desenvolvimento

## Objetivo do Software
O **EloGG** é uma aplicação desktop desenvolvida para simular, gerir e acompanhar estatísticas de jogadores e partidas do jogo *League of Legends*. O sistema permite organizar dados de desempenho de forma intuitiva e eficiente.

## Funcionalidades do Sistema (Requisitos)
- Cadastro e autenticação de utilizadores/jogadores.
- Registo e consulta de estatísticas de partidas.
- Gestão e listagem de perfis e campeões.
- Interface gráfica intuitiva para navegação nos dados.

## Tecnologias Aplicadas
- **Linguagem:** Java
- **IDE:** Apache NetBeans / Visual Studio Code
- **Interface Gráfica:** Java Swing
- **Base de Dados:** MySQL
- **Mapeamento/Persistência:** JPA / Hibernate
- **Versionamento:** Git e GitHub
